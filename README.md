# Lucas Venutto — Site Oficial

Primeira base profissional do site oficial.

## Rodar localmente
npm install
npm run dev

## Build
npm run build

## Cloudflare
Framework: Vite
Build command: npm run build
Output directory: dist

## Antes de publicar oficialmente
- substituir placeholders por fotos oficiais do Lucas;
- inserir links reais de Spotify, YouTube, Instagram e TikTok;
- configurar WhatsApp/e-mail comercial;
- cadastrar agenda real;
- adicionar press kit oficial.
